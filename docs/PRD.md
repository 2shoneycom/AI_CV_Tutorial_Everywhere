# PRD.md

## 초기 아이디어 — 2026-11-11

- 프로젝트명: AI CV Tutorial Everywhere.
- 목적: 사용자의 현재 화면 또는 현실 장면에서 사용법을 시각적인 단계별 튜토리얼로 안내한다.
- 대상: 남녀노소, 특히 고령자.
- 방식 1: 사용자 요청 시 현재 화면 위에 오버레이로 안내한다.
- 방식 2(확장): 카메라로 현실 장면을 인식하고 별도 화면 또는 스마트 글래스 등으로 안내한다.
- 예시: VS Code에서 React 프로젝트 시작, FastAPI 설치 후 시작, 카페 키오스크 메뉴 선택과 결제 단계 안내.
- 사용자 행동에 따라 다음 안내 위치와 내용을 변경하는 상호작용을 지향한다.

## 제품 방향 확정 — 2026-11-11

- 첫 출발점은 고령자를 위한 키오스크 안내다.
- 장기 목표는 컴퓨터뿐 아니라 TV, 휴대폰, 세탁기 등 다양한 상황에서 튜토리얼/가이드를 제공하는 AI 도우미다.
- 핵심 입력은 사용자가 보는 장면과 사용자와의 대화다. 대상 기기의 DOM, IDE 확장, 내부 API 등 기기별 연동을 필수 전제로 삼지 않는다.
- 사용자가 안내 필요성을 느끼고 프로그램을 실행하면 장면을 포착하고 상황을 파악한다.
- 안내할 근거가 충분하면 가이드를 제시하고, 상황이나 목표가 모호하면 필요한 추가 정보를 사용자에게 묻는다.
- 사용자 답변을 반영해 다시 판단하고 안내한다. 장기 목표가 모든 상황에서 항상 정확한 답을 보장한다는 의미는 아니다.

## 초기 테스트 구성

- 휴대폰 카메라로 대상 장면을 촬영하고 연결된 노트북에서 프로그램 실행과 안내 출력을 수행한다.
- 노트북에 촬영 영상과 시각적 안내를 함께 표시하는 구성을 초기 검증안으로 삼는다.
- 이 구성은 인식·질문·안내 흐름 검증용이며 최종 사용자의 출력 장치를 확정한 것은 아니다.

## 미확정 사항

휴대폰/노트북의 OS와 모델, 영상 연결 방식, 첫 키오스크 과제, 최종 출력 장치, AI 모델 및 배포 방식, 예산과 일정은 미확정이다. 개발자 온보딩은 첫 MVP 범위가 아니다.

구현 가능성 및 MVP 제안은 [검토 보고서](../report/2026-11-11-feasibility-review.md)에 기록했다. 보고서의 제안은 확정 요구사항이 아니다.

이후 사용자 설명에 따른 방향 보완은 [시각 관찰과 대화 중심 설계 검토](../report/2026-11-11-visual-dialogue-direction.md)에 기록했다. 기존 보고서의 구조 정보 우선 제안보다 본 문서의 최신 제품 방향을 우선한다.
