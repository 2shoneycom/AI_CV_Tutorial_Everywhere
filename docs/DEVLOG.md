# DEVLOG.md

## 2026-11-12 — 첫 카메라 안내 프로토타입 구현

- 승인된 기존 API 키를 .env.local에 복사하고 Git 제외 및 파일 권한 설정. 값은 문서/로그에 남기지 않음.
- Node.js 서버, 노트북 안내 화면, 휴대폰 카메라 화면, 촬영용 키오스크 구현.
- 이미지와 사용자 대화만 사용하는 Responses API 분석, 질문/안내/재관찰/완료 응답, 고정 분석 사진 강조 구현.
- 아이폰 입력 확인 후 Mac 연속성 카메라 선택 경로와 Safari 사진/HTTPS 경로 제공.
- 실제 API 검수에서 초기 gpt-4.1-mini의 위치 오류를 발견해 gpt-5.4로 보완.
- 상세 검증 및 제한: [구현 보고서](../report/2026-11-12-camera-guide-prototype.md).

## 2026-11-11 — 초기 테스트 구성 기록 및 원격 저장소 등록

- 휴대폰 카메라 입력과 노트북 실행·출력 구성을 PRD, ARCHITECTURE, DEV_PLAN에 반영했다.
- 사용자가 초기화한 Git 저장소에 `origin`으로 `https://github.com/2shoneycom/AI_CV_Tutorial_Everywhere.git`을 등록했다.
- 기존 커밋이 없어 첫 커밋 메시지는 `v0.01`로 제안한다. 커밋 및 푸시는 사용자가 직접 수행한다.
- 상세 보고서: [초기 테스트 구성 및 원격 저장소 설정](../report/2026-11-11-initial-test-and-git-remote.md).

## 2026-11-11 — 시각 관찰과 대화 중심 방향 정리

- 사용자가 첫 출발점을 고령자 키오스크 안내로 선택했다.
- 장기 목표를 컴퓨터 외 다양한 기기·현실 상황까지 포함하는 가이드 도우미로 명확히 했다.
- 기기 내부 연동을 필수로 하지 않고 장면 관찰과 추가 질문으로 안내 근거를 확보하는 방향을 PRD와 ARCHITECTURE에 반영했다.
- DEV_PLAN에는 해당 제약을 지키는 단계별 검증안을 미확정 제안으로 기록했다.
- 상세 보고서: [시각 관찰과 대화 중심 설계 검토](../report/2026-11-11-visual-dialogue-direction.md).
