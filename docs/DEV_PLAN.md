# DEV_PLAN.md

## 확정 범위

- 출발점: 고령자를 위한 키오스크 안내.
- 핵심 흐름: 장면 관찰과 사용자 대화로 상황을 파악하고 안내한다. 대상 기기 내부 연동을 필수로 하지 않는다.

## 단계별 검증안 — 제안, 일정 미정

### Phase 0 — 첫 과제와 평가 조건 정의

1. 휴대폰 카메라와 노트북 구성에서 OS·영상 연결 방식, 키오스크 유형과 첫 완료 과제 선정.
2. 명확한 장면, 목표가 모호한 장면, 글자가 안 보이는 장면, 오조작 사례 구성.
3. 안내 정확도, 질문의 유용성·횟수, 작업 완수율과 지연의 평가 방식 결정.

### Phase 1 — 관찰·질문·안내 반복 검증

1. 휴대폰 영상을 노트북으로 전달하고 제한된 키오스크 장면을 분석 입력으로 사용.
2. 목표와 상태가 부족하면 질문하고 사용자 답변으로 보완.
3. 한 단계 시각 안내 후 새 이미지로 결과 확인 및 복구.
4. 시뮬레이터를 쓰더라도 DOM/내부 상태는 안내 엔진에 제공하지 않고 평가 정답에만 사용.

### Phase 2 — 카메라 및 사용자 검증

1. 실제 촬영에서 흔들림·반사·가림과 재촬영 요청 처리.
2. 고령 사용자에게 안내 이해도와 질문 부담 평가.
3. 학습/개발에 사용하지 않은 레이아웃에서 일반화 및 안내 보류 동작 평가.

### Phase 3 — 다른 상황으로 확장 검증

1. 키오스크 외 도메인을 별도로 선정.
2. 공통 관찰·대화 흐름을 유지하며 필요한 절차 지식을 보완.
3. 도메인별 완수율과 한계를 검증한 뒤 지원 범위 확대.
