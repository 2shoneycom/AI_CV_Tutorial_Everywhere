## 무엇을/왜/어떻게

휴대폰 카메라 입력과 노트북 출력이라는 첫 테스트 구성을 로컬 웹 프로토타입으로 구현했다. 추가 npm 의존성 없이 Node.js 22 이상에서 실행한다. 사용자는 노트북에서 연결을 만들고 사진을 수신한 뒤 목표나 답변을 입력해 한 단계씩 안내받는다.

서버는 이미지와 최근 대화만 AI에 전달한다. 연습용 키오스크의 DOM, 버튼 좌표, 장바구니 상태를 AI에 공급하지 않는다. 자동 평가의 정답 좌표는 수동으로 주석한 테스트 이미지의 버튼 영역이며 추론 입력에 포함되지 않는다.

API 키는 사용자가 승인한 기존 프로젝트 파일에서 현재 프로젝트 .env.local로 복사했다. 값은 출력하거나 기록하지 않았으며 원본을 수정하지 않았다. git check-ignore 및 git ls-files로 제외 상태를 확인했다.

## 주요 파일

- src/server.js: HTTP/HTTPS 서버, 메모리 세션, 프레임 송수신, AI 호출 및 취소
- src/guide.js: 이미지 검증/크기 판독, 프롬프트, 구조화된 응답과 좌표 검증
- public/: 노트북, 휴대폰, 연습용 키오스크 UI
- test/: 키 노출 방지, 토큰 권한 분리, 입력/응답 검증, 오래된 요청 및 종료 처리
- scripts/evaluate-fixture.js: 합성 키오스크 이미지의 실제 API 평가. 별도 실행 시 API 비용 발생
- README.md: 실행법, 아이폰 연결 경로와 HTTPS 설정, 구현 제한

## 검증 결과

1. npm run check 통과.
2. npm test: 11/11 통과. 최초 서버 테스트는 샌드박스 포트 제한으로 실패했으며 승인된 실행 환경에서 모두 통과했다.
3. 브라우저에서 사진 업로드 → AI 질문 → 답변 입력 → 안내 생성 흐름을 실제 API로 확인했다.
4. 초기 gpt-4.1-mini는 음료명과 안내 문구는 맞췄지만 강조 박스가 제목 쪽에 놓였다. gpt-5.4로 바꾸는 것만으로도 같은 유형의 오차가 남았다. 따라서 이미지의 실제 가로/세로 크기를 읽어 좌표 변환 규칙을 함께 전달했다.
5. 보완 후 합성 사진 평가: 목표가 없으면 question, 아이스 아메리카노 목표가 있으면 guide 및 대상 중심이 버튼 안에 위치. 두 요청의 관측 지연은 각각 약 5.3초와 5.4초였다. [평가 원문](2026-11-12-fixture-evaluation.json)
6. 반환 박스의 외곽은 여전히 버튼보다 넓었다. 전체 박스를 정밀하게 식별했다고 주장하지 않고 현재 UI는 중심 위치 표시를 사용한다. 위 평가는 중심의 포함 여부만 검사하며 박스 IoU나 전반적 정확도 지표가 아니다.
7. 최종 브라우저 검수에서 주황색 중심 표시가 아메리카노 버튼 안에 있는 것을 확인했다. [화면](assets/2026-11-12-preview.png)
8. .env.local은 Git 추적 대상에서 제외되었다. 파일 내용을 정적 서버로 읽을 수 없는지 통합 테스트했다.

## 현재 제한과 다음 검수

- 실제 아이폰 연결, 카메라 권한, Mac 연속성 카메라 목록 노출, iOS 인증서 신뢰는 사용자의 기기로 검증해야 한다. 코드 경로가 있다는 것과 하드웨어에서 동작을 확인했다는 것은 다르다.
- 연속 영상은 약 1fps 사진 스트림이다. AI는 버튼 요청 시만 실행하며 자동 단계 감지나 AR 추적을 구현한 것은 아니다.
- 분석 사진과 라이브 영상을 분리했다. 과거 결과를 새로운 라이브 프레임에 겹치지 않는다.
- 매뉴얼 검색, OCR 기반 별도 위치 검증, 음성 입력, 개인정보 자동 마스킹, 실결제는 미구현이다.
- 샘플 2건 통과를 일반화 성능으로 해석하지 않는다. 반사·가림·기울기·위치 변경·잘못 누름에 대한 평가가 필요하다.
- 단일 로컬 세션용 서버다. 인터넷 공개 배포는 하지 않았다. 커밋과 푸시도 수행하지 않았다.

## 검수 순서

1. npm start → localhost:3000 → 새 연결 만들기.
2. 저장소의 합성 키오스크 사진으로 질문과 안내 확인.
3. 아이폰 + Mac 연속성 카메라를 연결하고 카메라 목록에서 선택.
4. 실제 촬영에서 메뉴 선택 → 옵션 선택 → 주문 확인 흐름 시험.
5. 연결 종료 후 촬영과 분석이 중지되는지 확인.
