# AI CV Tutorial Everywhere

보이는 장면과 사용자와의 대화만으로 다음 한 단계를 안내하는 실험용 프로토타입입니다. 첫 대상은 고령자를 위한 키오스크 안내입니다. **키오스크의 DOM, API, 내부 주문 상태를 읽지 않습니다.**

## 실행

Node.js 22 이상이 필요합니다. 외부 npm 패키지는 사용하지 않아 `npm install` 없이 실행됩니다.

```sh
npm start
```

Mac 브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다. 현재 작업 장비에는 승인된 기존 키를 `.env.local`에 설정했습니다. 다른 장비에서는 `.env.example`을 참고해 `.env.local`에 본인의 키를 설정하세요. 이 파일과 인증서 개인키는 Git에 포함하지 않습니다.

```sh
npm run check
npm test
```

실제 API 샘플 평가(요청 2회, API 비용 발생):

```sh
node --env-file=.env.local scripts/evaluate-fixture.js
```

## 가장 빠른 사진 테스트

1. 노트북 화면에서 **새 연결 만들기**를 누릅니다.
2. **노트북에서 사진 선택**으로 키오스크 사진을 엽니다. 저장소의 `report/assets/2026-11-12-kiosk.png`는 촬영용 페이지의 테스트 스크린샷입니다.
3. 목표를 비워 두고 **현재 장면 안내받기**를 눌러 추가 질문이 나오는지 봅니다.
4. “아이스 아메리카노 한 잔을 주문하고 싶어요”라고 답하고 다시 안내받습니다.
5. 실제 조작 후 새 사진을 보내고 다시 안내받습니다. **완료 감지는 요청 시점의 사진으로 수행하며 자동 분석은 아직 없습니다.**

## 아이폰 + Mac 연속성 카메라 (연속 촬영의 첫 선택)

이 경로는 아이폰을 Mac의 카메라 장치로 이용합니다. 아이폰 Safari에서 카메라 페이지를 여는 방식과 다릅니다.

1. [Apple 연속성 카메라 안내](https://support.apple.com/en-gb/102546)의 기기·OS 요건을 확인합니다. 같은 Apple 계정과 이중 인증 등이 필요하며, USB 연결에서는 아이폰이 Mac을 신뢰해야 합니다.
2. 아이폰을 Mac에 연결하고 키오스크를 볼 수 있게 고정합니다. USB 연결을 먼저 시험하면 편리합니다.
3. Mac의 `http://localhost:3000`에서 **새 연결 만들기 → 휴대폰 연결 및 사진 선택 → 연결 카메라 시작**을 누르고 브라우저의 카메라 권한을 허용합니다.
4. 최초에는 기본 카메라가 열릴 수 있습니다. 권한 허용 후 **카메라 선택** 목록에서 아이폰을 선택하고 **연결 카메라 시작**을 다시 누릅니다. 아이폰이 목록에 없으면 Apple 연결 조건과 브라우저 카메라 설정을 확인합니다.
5. 영상이 노트북에 수신되면 목표를 입력하고 안내받습니다. **카메라 중지**는 촬영만, **연결 종료**는 세션과 서버의 사진·대화를 종료합니다.

이 연동의 실제 아이폰 하드웨어 검증은 아직 필요합니다. 브라우저 또는 기기가 지원하지 않으면 아래 사진 전송 경로를 사용할 수 있습니다.

## 아이폰 Safari에서 사진 전송

1. 아이폰과 Mac을 같은 신뢰할 수 있는 Wi-Fi에 연결합니다.
2. 노트북에서 만든 `http://<Mac IP>:3000/camera#...` 주소를 아이폰 Safari에서 엽니다. Mac 방화벽이 Node.js의 연결을 허용해야 합니다.
3. **사진 촬영 / 선택**을 눌러 사진을 보냅니다. 노트북에 최신 사진이 나타납니다.
4. HTTP의 일반 LAN 주소에서는 브라우저 보안 규칙 때문에 **연속 촬영 시작**이 비활성화됩니다. 이는 서버 오류가 아닙니다. HTTP는 암호화되지 않으므로 테스트 장면만 사용하세요.

연결 주소에는 이 세션에 사진을 전송할 수 있는 토큰이 포함됩니다. 다른 사람에게 공유하지 마세요. 새 연결은 이전 연결을 무효화하며 연결은 2시간 뒤 만료됩니다. 한 서버에서 한 세션만 지원합니다.

## 아이폰 Safari 연속 촬영을 위한 HTTPS (선택)

서버는 `TLS_CERT`, `TLS_KEY`로 HTTPS를 지원합니다. **아이폰이 신뢰하는 인증서**가 필요하며, 단순히 경고를 넘긴 자체 서명 인증서는 카메라 동작을 보장하지 않습니다.

로컬 개발용 [mkcert](https://github.com/FiloSottile/mkcert)를 사용하는 경우, 설치 및 인증서 신뢰 설정은 사용자가 직접 수행합니다. 예시에서 `192.168.0.21`은 본인의 Mac IP로 바꾸세요.

```sh
mkdir -p .certs
mkcert -install
mkcert -key-file .certs/key.pem -cert-file .certs/cert.pem localhost 127.0.0.1 ::1 192.168.0.21
mkcert -CAROOT
```

`mkcert -CAROOT` 위치의 **rootCA.pem 공개 인증서만** 아이폰에 설치하고 인증서 신뢰 설정을 완료합니다. `rootCA-key.pem` 개인키는 전송하지 않습니다. 환경에 따라 프로파일 설치 절차가 다르므로 mkcert 문서와 iOS 설정을 확인하세요. 개발 CA 신뢰는 테스트 후 필요에 따라 제거합니다.

`.env.local`에 다음을 설정하고 서버를 재시작합니다.

```dotenv
TLS_CERT=.certs/cert.pem
TLS_KEY=.certs/key.pem
```

노트북에서 `https://localhost:3000`을 열고 새 연결을 생성합니다. 아이폰에서 새 HTTPS 주소를 열어 **연속 촬영 시작**을 누릅니다. 화면을 벗어나거나 화면이 잠기면 촬영이 중지되므로 Safari를 켜 두세요. IP가 바뀌면 인증서를 다시 발급해야 합니다. 서버의 HTTPS 실행 경로는 구현했으며 실제 아이폰 인증서 설치/스트리밍 검증은 미완료입니다.

## 화면과 분석의 관계

- 휴대폰은 최대 긴 변 1280px JPEG를 약 1초 간격으로 전송합니다. 이는 저속 프레임 스트리밍이며 30fps 영상 전송이 아닙니다.
- 최신 영상과 **분석 당시의 고정 사진**을 분리해서 표시합니다. 주황색 중심 표시는 분석 사진 위에만 그립니다. 모델이 반환한 박스의 외곽이 부정확할 수 있어 중심 위치를 사용합니다. 현재 영상에 대한 실시간 좌표 추적은 구현하지 않았습니다.
- 분석은 버튼을 누를 때만 실행합니다. 이미지와 최근 최대 8턴 대화가 OpenAI Responses API로 전달됩니다. 현재 평가용 기본 모델은 `gpt-5.4`이며 `.env.local`의 `OPENAI_MODEL`로 변경할 수 있습니다. 모델별 정확도 비교는 미완료입니다.
- 목표 불명확 → 질문, 시야 불명확 → 재관찰 요청, 대상 확인 → 한 단계 안내, 관찰된 목표 달성 → 완료 확인으로 응답합니다.
- 좌표 범위를 검증하며 잘못된 박스는 재관찰 요청으로 전환합니다. 구조 검증이 안내 내용의 정확성을 보장하지는 않습니다.
- 연습용 키오스크는 [http://localhost:3000/kiosk](http://localhost:3000/kiosk)에서 열 수 있습니다. 다른 화면에 띄워 촬영하고 메뉴 위치 변경·뒤로 가기도 시험하세요. 주문 상태는 이 페이지의 브라우저 안에만 있습니다.

## 데이터와 현재 제한

- API 키는 서버에서만 사용합니다. 정적 파일 경로를 명시적으로 제한하여 `.env.local`과 서버 소스를 제공하지 않습니다.
- 앱은 사진과 대화를 디스크에 저장하지 않습니다. 현재 프레임·대화는 서버 메모리, 표시한 분석 사진은 브라우저 메모리에 남으며 연결 종료/페이지 종료 시 정리합니다.
- Responses 요청은 `store:false`입니다. 이는 이 앱의 저장 정책이며 OpenAI의 제공자 측 데이터 보존 전체를 없앤다는 의미는 아닙니다. 자동 개인정보 마스킹은 아직 없습니다.
- 카메라 토큰은 사진 전송만 허용합니다. 노트북 소유자 토큰만 조회·분석·종료할 수 있습니다. 세션 생성은 loopback 요청과 localhost 호스트만 허용합니다.
- 동시에 한 분석, 요청 간 최소 간격, 세션당 60회 분석, 45초 분석 제한을 둡니다. 외부 공개 서비스용 인증·운영 구조는 아니므로 인터넷에 포트를 개방하지 마세요.
- 음성 출력은 브라우저 읽어주기를 사용하며 한국어 음성 지원은 OS/브라우저에 따라 다릅니다. 음성 입력은 미구현입니다.
- 실제 결제, 자동 클릭/조작, 매뉴얼 검색, 고령자 사용자 평가, 손 촬영 보정, 자동 단계 전환은 아직 범위에 포함하지 않습니다.
